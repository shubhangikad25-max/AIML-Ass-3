# Regression Models and Gradient Descent

## Project Description

This project demonstrates the implementation of **Regression Models** and **Gradient Descent optimization** using Python.

The real-world application used in this project is **House Price Prediction**.

The project consists of two parts:

1. **Multiple Linear Regression** for predicting house prices.
2. **Gradient Descent** implemented from scratch for Linear Regression.

---

## Objectives

* Develop a regression model for a real-world application.
* Predict house prices using multiple input features.
* Evaluate the regression model using appropriate performance metrics.
* Implement Gradient Descent for Linear Regression.
* Analyze the convergence of Gradient Descent using graphs.
* Study the effect of different learning rates.

---

## Dataset

A small sample House Price dataset is created directly in Python.

### Input Features

* Area of the house
* Number of bedrooms
* Number of bathrooms

### Target Variable

* House price

The house price is represented in **lakhs**.
